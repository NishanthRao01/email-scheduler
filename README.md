# ReachInbox Email Scheduler

Full-stack email scheduling system built as part of the Outbox Labs SDE Internship assignment.

## Stack

### Backend
- TypeScript
- Express.js
- PostgreSQL
- BullMQ
- Redis
- Elasticsearch

### Frontend
- React
- TypeScript
- Tailwind CSS

### Integrations
- Google OAuth
- Slack OAuth
- Ethereal Email
